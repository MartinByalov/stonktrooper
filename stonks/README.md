# Stonks - самостоятелно копие

Тази папка съдържа генератора, popup прозореца с неговите стилове, данните и всички 186 PNG изображения. Оригиналните файлове на платформата не са променени.

## Съдържание

- `index.html` - самостоятелна страница за разглеждане на колекцията и бутон за отваряне на popup-а.
- `popup-demo.js` - свързва бутона с popup-а, без зависимост от sidebar-а.
- `nft-popup.js` - HTML, вградени CSS стилове, отваряне, затваряне, генериране и сваляне на PNG.
- `js/stonk-generator.js` - зарежда колекцията и рисува изображенията върху canvas.
- `data/traits-config.json` - конфигурация на характеристиките и слоевете.
- `data/stonks-collection.json` - предварително създадената колекция от 10 000 персонажа.
- `assets/` - всички локални PNG слоеве.
- `generate-collection.mjs` - Node.js скрипт за повторно създаване на данните за колекцията.
- `README-original.md` - копие на оригиналната документация; пътищата в нея са за първоначалната интеграция.

## Стартиране

При работещ development сървър на проекта отвори:

```text
http://localhost:3000/stonks/index.html
```

Натисни „</> Отвори Stonks“, за да видиш копието на popup-а от sidebar-а.

Папката може да се копира на друг статичен HTTP сървър. Не е нужно да копираш sidebar-а или останалата платформа. Отваряне чрез `file://` не се поддържа заради ES modules и `fetch`.

## Вграждане на popup-а в друга страница

Ако HTML страницата е до тази папка:

```html
<button type="button" id="stonksButton">&lt;/&gt;</button>
<script type="module">
  import { open } from './stonks/nft-popup.js';

  document.getElementById('stonksButton').addEventListener('click', () => {
    open().catch(console.error);
  });
</script>
```

Пътищата до генератора, JSON файловете и изображенията се определят спрямо местоположението на `nft-popup.js`. Запази структурата на папката.

## Адаптации в копието

- Popup-ът зарежда генератора от собствената папка, а не от оригиналната `tools/thestonks`.
- Font Awesome иконите в popup-а са заменени с Unicode символи, за да няма зависимост от външен шрифт.
- Самостоятелната страница не зарежда платформения accessibility widget.
- Генераторът, JSON данните и PNG слоевете са копирани без промени.

## Повторно създаване на колекцията

От терминал, отворен в тази папка:

```sh
node generate-collection.mjs
```

Това презаписва локалния `data/stonks-collection.json`. Не е необходимо за нормалното използване на готовата колекция и не създава PNG слоевете.

# Stonktrooper

Browser game built with React, TypeScript and Vite.

## Development

```sh
npm ci
npm run dev
```

## Validation and production build

```sh
npm run lint
npm run build
npm run preview
```

`npm run clean` removes the generated `dist` directory. Deployment to GitHub
Pages runs the type check and production build. Temporary test files, browser
audits and logs are not part of the maintained project.

Mobile validation notes and outstanding device checks are in
`docs/mobile-validation.md`.
